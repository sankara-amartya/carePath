Visual language, component library, and UX principles for the CarePath elder care platform — inspired by warmth, trust, and calm clarity.

Design philosophy
Care feels different here

CarePath is used in moments of stress, exhaustion, and worry. Every design decision must answer: does this reduce cognitive load? Does it feel like a steady hand? The visual language borrows from Clearmind's warmth — deep, calming backgrounds, generous whitespace, soft rounded forms — and shifts the palette from purple/therapy to forest green/trust.

Calm authority
Like a nurse who's seen everything — confident, unhurried, never alarming unless truly necessary.
Family warmth
This is about people who love each other. Copy, colors, and flow should feel human, not clinical.
Effortless clarity
A caregiver has 60 seconds. Every screen must communicate its purpose in 3 seconds flat.
Invisible intelligence
AI works in the background. Never show spinners or prompts — just better outcomes, quietly delivered.

Motion & interaction
How things move

Motion must always feel purposeful. Inspired by Clearmind's calm transitions — nothing should startle.

Screen transitions — 280ms ease-out
Slide up from bottom for new screens. Slide right for back navigation. Never use fade — too slow in a care context.
Medication logged — 160ms spring
The check icon scales from 0.8→1.0 with a slight bounce (spring: stiffness 200, damping 14). Green fill sweeps left to right. Haptic feedback on native.
AI summary streaming — token by token
Text appears token by token with a cursor blinking at 1s interval. No loading spinner — the content is the animation. Mint glow on the card border fades in.
Critical alert — pulse 400ms
Red border pulses twice (opacity 1 → 0.4 → 1 → 0.4) then holds. Haptic: long buzz on mobile. Never auto-dismiss a critical alert.
Health slider — real-time
Thumb follows finger with zero lag. Track fill updates instantly. Numeric value fades in above thumb. No debounce on visual — debounce only the API call (300ms).
Copy voice
Write like a trusted friend

Every word in CarePath should sound like it was written by someone who has been a caregiver — practical, warm, never condescending.

Do this
"Dad hasn't taken Metformin yet. Want to send a reminder?"
"Appetite has been low for 3 days — worth mentioning at Thursday's appointment."
"All caught up! You're doing great."
Avoid this
"Patient ID 4421 has a missed medication event. Compliance: 87%."
"Warning: Anomaly detected in health_checks table. Z-score: 1.7."
"Error: Unable to process AI inference request."
